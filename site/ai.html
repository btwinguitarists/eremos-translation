Use Eremos Thai Bible with AI

Retrieve Thai Bible passages word for word, search the text, and explore published translation notes.

Complete AI-assisted draft under review · CC0 public domain · Read-only · No Eremos account needed

Copy this MCP server URL:

https://mcp.eremosapp.com/mcp

Choose Streamable HTTP and no authentication. The connector reads public translation data; it cannot edit verses or access private discipleship accounts.

ChatGPT

Open Plugins → + → Add custom MCP server. Name it Eremos Thai Bible, enter the URL above, and choose no authentication. Review the connection warning and create the plugin. Inspect its four tools, install it, then select it with @ in a new conversation. Your account and workspace must allow custom servers.

Claude

Open Customize → Connectors → + Add → Add custom connector. Enter Eremos Thai Bible and the server URL. Choose No sign in, leave credentials and request headers empty, and add it. Enable it in the conversation under + → Connectors. Team and Enterprise workspaces may require an administrator first.

Gemini CLI

With Gemini CLI installed, run:

gemini mcp add --transport http --scope user eremos-bible https://mcp.eremosapp.com/mcp
gemini mcp list

Restart an already-running CLI and inspect tools with /mcp. This setup applies to Gemini CLI, not the Gemini consumer chat app.

Help connecting

Use the exact /mcp URL, enable the connector, and ask for a tool call. An answer without a tool call does not verify retrieval. A browser GET is not an MCP health check. Requests and search terms go to the hosted service; use public Bible text and references, not sensitive personal information.
